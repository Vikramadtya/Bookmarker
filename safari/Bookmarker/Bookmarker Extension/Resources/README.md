# Bookmarker browser extension

Saves the current tab to your Bookmarker, with a folder and tags.

1. Open `chrome://extensions` (Edge: `edge://extensions`) and turn on **Developer mode**.
2. Choose **Load unpacked** and select this `extension` folder.
3. Open the extension's options, enter your Bookmarker address (for example
   `https://your-bookmarker.example.com`) and allow access when asked.
4. Sign in to Bookmarker in the same browser, then click the toolbar button or press
   <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> on any page.

It uses your existing sign-in cookie; nothing is stored in the extension except the address.
